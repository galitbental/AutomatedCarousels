# Carousel Studio

A local desktop app that turns **Be Wished** product photos (a poem card plus jewelry in its gift box) into finished,
on-brand Instagram carousels: 7–10 slides (1080×1350 PNG), plus a caption and hashtags. The owner reviews, edits and
approves every step in the app.

- **Claude Code** (`claude -p`) reads poem cards, drafts product facts, writes the carousel plan and checks images.
- **ChatGPT**, driven through Claude in Chrome, generates the images.
- Slide text is rendered locally from HTML templates, so generated images never contain text.

## Requirements
- Windows 10/11, Python 3.11+ and Google Chrome.
- [Claude Code](https://claude.com/claude-code) CLI, installed and logged in.
- For automatic image generation: the Claude in Chrome extension, and a ChatGPT account logged in within that Chrome
  profile. Chrome must save downloads without asking where to save.

## Start
| | |
|---|---|
| `CarouselStudio.bat` | Real use. The first run creates `.venv` and installs `requirements.txt`. |
| `CarouselStudio-Demo.bat` | Demo on a separate `_demo/` copy, with placeholder images and no Claude/ChatGPT calls (no cost). |
| `RunTests.bat` | Automated tests. `RunTests.bat -m live` runs real Claude/ChatGPT smoke tests, which cost money. |

## How it works
1. Put product photos into `DataFromUser/`. **The file name is the SKU**, e.g. `GodDaughter1_G_IC.jpg`.
2. Work through the six stages; each ends with **Approve**:
   1. **Intake:** recipient, giver, event and tone, prefilled from the poem-card catalog.
   2. **Facts:** the approved product facts for the style.
   3. **Plan:** hooks, slides, caption and hashtags, checked against the brand spec.
   4. **Images:** generated by ChatGPT and checked by Claude.
   5. **Slides:** rendered to PNG.
   6. **Final:** saved to `Carousels/<date>_<SKU>_<event>/`, and the input photo is deleted.

## Folders
| Folder | Content | In git |
|---|---|---|
| `app/` | Python server (Flask), services, slide templates, web UI | yes |
| `tests/` | unit, API, regression (golden), launcher and UI tests | yes |
| `doc/` | design, SRS, brand content spec, user guide, test report | yes |
| `data/styles.json` | jewelry type table (SKU code → style folder) | yes |
| `data/` (other files) | settings and history ledgers, created by the app | no |
| `DataFromUser/`, `RealProductPhotos/`, `StyleLibrary/`, `Carousels/` | photos and finished carousels | no |

The photo folders are not in the repository. On a new machine, create them and copy the photos in. **System check** in
the app shows which style folders are expected.
